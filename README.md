# 🎟️ Билет
### Генератор экзаменационных билетов

**Лабораторная работа № 2 · Python + Tkinter**

Выбор студента, выдача трёх вопросов и полная история результатов в Excel.

</div>

---

## ✨ Возможности

| Возможность | Описание |
| --- | --- |
| 👥 Группы и студенты | Группы берутся из листов Excel, студенты — из колонок A и B |
| 🎲 Случайный билет | Новому студенту назначается один допустимый билет |
| 🔁 Повторная выдача | Используется номер из самой первой записи этого студента |
| 📚 Журнал без потерь | Каждая выдача дописывается новой строкой |
| 🛡️ Валидация | Некорректные билеты пропускаются, подробности пишутся в лог |
| 🔒 Защита от блокировки | Запись можно повторить, закрыв книгу в Excel |
| ⎋ Удобный возврат | `Esc` закрывает только диалог билета |

## 🖥️ Интерфейс

Чистый интерфейс на Tkinter/ttk ведёт по шагам **группа → студент**. Кнопка
выдачи доступна только при корректном выборе и загруженных файлах. Билет и
вопросы появляются в отдельном диалоге. После закрытия приложение готово к
следующему студенту.

## 📥 Подготовка файлов

Положите файлы `students.xlsx` и `tickets.docx` в ту же папку, что и `main.py`.

### `students.xlsx`

- Каждый лист — группа, его название используется как имя группы.
- Строка 1 — заголовок.
- Строка 2 и далее: колонка **A — фамилия**, **B — имя**.
- Пустая группа разрешена; пустые строки игнорируются.

| A — Фамилия | B — Имя |
| --- | --- |
| Иванов | Иван |
| Петрова | Анна |

### `tickets.docx`

Каждый заголовок билета и вопрос — отдельный абзац Word. Билет должен содержать
не менее трёх нумерованных вопросов. Если вопросов больше, показываются первые
три.

```text
Билет 1
1. Первый вопрос
2. Второй вопрос
3. Третий вопрос

Билет 2
1. Первый вопрос
2. Второй вопрос
3. Третий вопрос
```

Билет с некорректным заголовком, повторным номером или менее чем тремя вопросами
пропускается; остальные билеты продолжают обрабатываться.

### `results.xlsx`

Журнал создаётся автоматически. Новая строка добавляется сразу при генерации;
предыдущие записи не редактируются.

| Колонка | Заголовок | Описание |
| --- | --- | --- |
| A | Группа | Имя листа Excel |
| B | Фамилия | Фамилия студента |
| C | Имя | Имя студента |
| D | Номер билета | Назначенный номер |
| E | Дата и время | Время выдачи |
| F | Повтор | `нет` — первая выдача, `да` — повтор |

Студент идентифицируется по точному сочетанию **группа + фамилия + имя**.
Повторная выдача использует билет из первой записи и добавляет новую строку,
поэтому история сохраняет хронологию всех генераций.

> Файлы студентов и результатов локальные и не включены в репозиторий.
> Не добавляйте настоящие персональные данные в Git.

## 🚀 Запуск (Windows)

Нужны Python 3.10+ и Tkinter.

```powershell
python -m pip install -r requirements.txt
python main.py
```

Если отсутствует `students.xlsx` или `tickets.docx`, приложение покажет понятную
ошибку, запишет детали в `ticket_generator.log` и не завершится аварийно.
Если `results.xlsx` заблокирован Excel, закройте его и выберите повтор записи.

## 🧪 Тесты

```powershell
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

Тесты покрывают чтение групп и студентов, парсинг билетов с пропуском ошибок,
дозапись журнала и повторное назначение номера из самой первой записи.

## ✅ Критерии приёмки

- [x] Выбор группы показывает студентов соответствующего листа.
- [x] Кнопка активируется только после выбора группы и студента.
- [x] Отображаются назначенный билет и три вопроса.
- [x] Повтор использует номер из первой записи и записывается как `да`.
- [x] `Esc` закрывает только окно результата.
- [x] Результаты немедленно дописываются без изменения истории.
- [x] Отсутствующие источники, пустые группы, блокировка и ошибки билетов обработаны.
